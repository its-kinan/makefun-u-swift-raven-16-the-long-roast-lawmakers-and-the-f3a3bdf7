One original satirical sentence roasting lawmakers who would regulate artificial intelligence but cannot convert a file to PDF: they draft a 400-page AI law, then halt the hearing while a staffer is summoned to turn the draft itself into a PDF. A deterministic program writes the line to `/output/entry.txt` — no network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
